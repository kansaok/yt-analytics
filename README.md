# Saya mau buat aplikasi untuk Youtube Analitic - Dokumen Perencanaan

Hasil export dari Nemuz. Isi folder ini:

- `PROMPT.md` - prompt siap tempel untuk AI coding agent (Claude Code, Cursor, Codex, dll).
- `prd/` - PRD. Mulai dari garis besar, lalu detail tiap bagian:
  - `prd/00-garis-besar.md`
  - `prd/01-product-summary.md`
  - `prd/02-scope.md`
  - `prd/03-key-features.md`
  - `prd/04-user-journey.md`
  - `prd/05-quality-requirements.md`
  - `prd/06-technology-choices.md`
  - `prd/07-system-design.md`
  - `prd/08-data-model.md`
  - `prd/09-apis-integrations.md`
  - `prd/10-risks-open-questions.md`
- `phases/` - task per fase beserta kriteria penerimaannya, dikerjakan berurutan:
  - `phases/01-fase-1.md`
  - `phases/02-fase-2.md`
- `DESIGN.md` - arah tampilan dari template yang kamu pilih (warna, font, komponen). `antislop.md` adalah filter kualitas UI pihak ketiga (MIT, lisensi di `ANTISLOP-LICENSE`); keduanya dibaca agent sebelum membangun antarmuka.
